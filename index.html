ساختار وب را با HTML یاد بگیرید

از اولین تگ تا عناصر معنایی، فرم‌های استاندارد، دسترس‌پذیری و جدیدترین قابلیت‌های بومی مرورگر — سیزده فصل، با مثال‌های کد واقعی.

شروع مطالعه
index.html 
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا</h1>
</body>
</html>
۰۱

آشنایی با HTML

HTML (مخفف HyperText Markup Language) زبان نشانه‌گذاری استانداردی است که ساختار و محتوای صفحات وب را مشخص می‌کند. هر صفحه از تعدادی «عنصر» تشکیل شده که هرکدام با یک «تگ» مشخص می‌شوند. HTML ظاهر صفحه را کنترل نمی‌کند — این کار بر عهده CSS است — بلکه معنا و ساختار محتوا را تعریف می‌کند.

ساختار پایه یک سند

boilerplate.html 
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>عنوان صفحه</title>
</head>
<body>
  <h1>سلام دنیا</h1>
  <p>این یک پاراگراف است.</p>
</body>
</html>

برای صفحات فارسی همیشه lang="fa" و dir="rtl" را روی تگ <html> بگذارید تا جهت متن و رفتار پیش‌فرض عناصر (فرم‌ها، اسکرول‌بار) درست تنظیم شود.

اجزای یک تگ

  • تگ باز و بسته: <p> ... </p>
  • عنصر خالی (بدون تگ بسته): <br>، <img>، <input>، <hr>
  • ویژگی (Attribute): جفت‌های name="value" داخل تگ باز
example.html 
<a href="https://example.com" target="_blank" rel="noopener">لینک</a>
<img src="pic.jpg" alt="توضیح تصویر" width="300">

متن و لیست‌ها

عناوین و پاراگراف

headings.html 
<h1>عنوان اصلی</h1>
<h2>زیرعنوان</h2>
<h3>زیرعنوان کوچک‌تر</h3>
<p>یک پاراگراف متنی است.</p>

در هر صفحه فقط یک <h1> باید وجود داشته باشد و سطح عنوان‌ها بدون پرش استفاده شود؛ این هم به سئو و هم به دسترس‌پذیری کمک می‌کند.

تگ‌های تاکیدی و درون‌خطی

تگ کاربرد

<span> بسته‌بندی متن برای استایل‌دهی، بدون معنای خاص
<code> نمایش قطعه کد
<mark> هایلایت کردن متن
<small> متن ریزتر و توضیحات جانبی

۰۳

عناصر معنایی (Semantic HTML5)

عناصر معنایی به مرورگر، موتورهای جست‌وجو و فناوری‌های کمکی می‌گویند هر بخش چه نقشی دارد — نه فقط چگونه به نظر برسد. استفاده از این عناصر به‌جای <div> برای همه‌چیز، استاندارد امروز توسعه وب است.

عنصر نقش
<header> سربرگ صفحه یا یک بخش
<nav> بخش ناوبری و لینک‌های اصلی
<main> محتوای اصلی صفحه (فقط یک‌بار)
<article> محتوای مستقل و قابل‌انتشار جداگانه
<section> بخش‌بندی موضوعی محتوا
<aside> محتوای جانبی و مرتبط
<footer> پاورقی صفحه یا یک بخش
<figure> تصویر یا نمودار همراه با زیرنویس
semantic.html 
<body>
  <header>
    <h1>نام سایت</h1>
    <nav>
      <a href="/">خانه</a>
      <a href="/about">درباره ما</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>عنوان مقاله</h2>
      <p>متن مقاله...</p>
    </article>
    <aside>مطالب مرتبط</aside>
  </main>

  <footer>&copy; ۱۴۰۴</footer>
</body>

لینک‌ها، تصاویر و رسانه

لینک‌ها

links.html 
<a href="page.html">لینک داخلی</a>
<a href="https://example.com" target="_blank" rel="noopener noreferrer">لینک خارجی</a>
<a href="mailto:info@example.com">ایمیل</a>
<a href="tel:+989120000000">تماس تلفنی</a>
<a href="#section2">لینک به بخشی از همین صفحه</a>

برای لینک‌هایی که با target="_blank" باز می‌شوند، همیشه rel="noopener noreferrer" اضافه کنید تا از دسترسی صفحه جدید به window.opener جلوگیری شود.

تصاویر واکنش‌گرا

images.html

<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="توضیح تصویر">

<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="توضیح تصویر">
</picture>

</video>

ساختار کلی form

form-structure.html 
<form action="/submit" method="post">

...
  • action مشخص می‌کند اطلاعات فرم به چه آدرسی ارسال شوند.
  • method روش ارسال اطلاعات را مشخص می‌کند.
  • GET معمولاً برای جست‌وجو و دریافت اطلاعات استفاده می‌شود.
  • POST معمولاً برای ارسال اطلاعات به سرور استفاده می‌شود.
  • enctype="multipart/form-data" برای فرم‌هایی که فایل ارسال می‌کنند ضروری است.

اعتبارسنجی HTML5

HTML می‌تواند قبل از ارسال فرم، برخی خطاهای ورودی را به صورت خودکار بررسی کند.

validation.html 
<input

type="email"
required
>

ویژگی required ورود مقدار را اجباری می‌کند. ویژگی‌های min و max محدوده عددی را مشخص می‌کنند و minlength و maxlength برای محدود کردن تعداد کاراکترها استفاده می‌شوند.

button

type کاربرد
submit ارسال فرم
reset بازگرداندن مقادیر فرم به حالت اولیه
button دکمه معمولی بدون رفتار پیش‌فرض

اگر type را برای یک button داخل فرم مشخص نکنید، رفتار پیش‌فرض آن معمولاً مانند submit خواهد بود؛ بنابراین بهتر است نوع دکمه را همیشه به صورت صریح مشخص کنید.

همیشه از label با ویژگی for متصل به id ورودی استفاده کنید. این کار هم دسترسی‌پذیری فرم را بهتر می‌کند و هم باعث می‌شود با کلیک روی متن label، ورودی مربوطه فوکوس یا انتخاب شود.

متادیتا و سئوی پایه

head.html 
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>عنوان صفحه | نام سایت</title>
</head>

تگ viewport برای واکنش‌گرا بودن صفحه در موبایل ضروری است؛ بدون آن، مرورگر موبایل صفحه را با عرض دسکتاپ رندر می‌کند.

08

بهترین شیوه‌ها

  • همیشه از عنصر معنایی مناسب استفاده کنید، نه <div> برای همه‌چیز.
  • برای دکمه‌های قابل‌کلیک از <button> استفاده کنید، نه <div onclick>.
  • هر <img> باید alt داشته باشد؛ برای تصاویر تزئینی alt="" بگذارید.
  • ساختار عنوان‌ها را سلسله‌مراتبی و بدون پرش نگه دارید.
  • فرم‌ها را با label و اعتبارسنجی بومی (required, pattern, min, max) کامل کنید.
  • پیش از افزودن جاوااسکریپت برای رفتار رابط کاربری، بررسی کنید آیا HTML بومی (dialog, popover, details) همان کار را انجام می‌دهد.
  • برای لینک‌های target="_blank" همیشه rel="noopener noreferrer" اضافه کنید.
